  - каждое число сопоставлено с Evidence
---
## Процедура
1. Извлеки все числа из черновика (проценты, цены, мультипликаторы, суммы).
2. Для каждого найди факт в Evidence: совпадение с допуском округления или явный расчёт из фактов Evidence.
3. Проверь, не противоречат ли выводы фактам (направление динамики, знак, порядок величин).
4. Проверь таблицу прогнозов: у каждого есть горизонт и уверенность.
5. Verdict: `ok`, если нарушений нет; иначе `fail`.

## Формат failed_claims
`{claim: "<цитата из отчёта>", reason: "нет в Evidence | противоречит: <факт> | нет горизонта"}`

Дата среза, номера источников `[n]`, горизонты 30/90/180 и уверенности прогнозов источника не требуют.
