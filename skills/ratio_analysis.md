## Набор мультипликаторов
- **P/E** = цена / EPS (TTM). Для убыточных компаний не применяется.
- **EV/EBITDA** = (капитализация + долг − кэш) / EBITDA.
- **FCF yield** = FCF / капитализация.
- **Debt/EBITDA** = совокупный долг / EBITDA.

## Ориентиры по секторам (для интерпретации)
| Сектор | P/E | EV/EBITDA | Debt/EBITDA |
|---|---|---|---|
| Технологии | 20–35 | 15–25 | < 1.5 |
| Потребительский | 15–25 | 10–16 | < 2.5 |
| Финансы | 8–15 | н/п | н/п |
| Энергетика | 8–15 | 4–8 | < 2 |
| Коммунальные | 14–20 | 9–12 | < 5 |

## Обязательно
Сравнение с собственной 5-летней медианой компании важнее сравнения с сектором. Нет истории — это гэп данных.

## Типовые ошибки
- смешение TTM и forward-оценок;
- EV без вычета кэша;
- выводы по P/E для финансового сектора без P/B.
