---
name: source_logging
description: при любом извлечении фактов из результатов инструментов
inputs: [tool_result]
outputs: Evidence[]
tools_required: []
quality_checklist:
  - у каждого факта есть source_url из результата инструмента
  - значение перенесено без округления
  - published_at заполнен, если известен
---
## Правило
Факт без `source_url` не существует. Если инструмент не вернул URL — факт не записывается.

## Формат Evidence
`{fact: "P/E (TTM) AAPL", value: 29.4, source_url: "https://finance.yahoo.com/quote/AAPL", published_at: null}`

## Приоритет источников
1. SEC EDGAR (10-K, 10-Q, 8-K) — первичная отчётность.
2. Официальные пресс-релизы и IR-сайт эмитента.
3. Рыночные данные (Yahoo Finance / Stooq).
4. Новостные агрегаторы — только для событий, не для финансовых показателей.

При конфликте значений записываются оба факта; конфликт фиксирует Risk Officer.

## Типовые ошибки
- склейка нескольких чисел в один факт;
- перенос числа из заголовка новости как финансового показателя;
- «примерные» значения вместо точных.
